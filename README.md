# Nike Sales Dashboard | Advanced Excel

## Project Overview
Created an interactive Excel dashboard to analyze Nike sales data by product, region, retailer, and sales method.

## Key Features
- Interactive Excel Dashboard
- KPI Cards
- PivotTables and Pivot Charts
- Interactive Slicers
- Sales and Profit Analysis
- Product and Region Analysis

## Project Objectives
- Cleaned and organized raw sales data.
- Calculated total sales, units sold, and operating profit.
- Identified top-performing products and regions.
- Analyzed sales trends for data-driven decisions.

## Tools Used
- Microsoft Excel
- Advanced Excel
- PivotTables
- Pivot Charts
- Slicers
- Excel Formulas

## Project Outcome
Developed an interactive dashboard to convert raw Nike sales data into meaningful business insights and support better decision-making.
